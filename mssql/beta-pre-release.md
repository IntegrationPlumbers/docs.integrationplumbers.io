# The SQL Server Open Beta has ended

The SQL Server Open Beta has ended, and the SQL Server plug-in is now generally available. Open Beta licence keys stop working on 2026-10-31. To move to the generally available release, install it as described in [Moving from the Open Beta](install-and-upgrade.md#from-beta): the beta plug-in `ip.em.xmsb` is separate from the general release `ip.em.xmss`, so it is a fresh install, not an upgrade.

What this page used to carry now lives elsewhere: what the release covers and its boundaries in [What's new](whats-new.md#ga), the licence statuses in [Troubleshooting](troubleshooting.md#license), and how to report a finding in [Troubleshooting](troubleshooting.md#reporting).
